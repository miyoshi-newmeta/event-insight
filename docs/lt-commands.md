# LTセッション コマンド早見表 (14:10〜14:55)

すべてDiscordの入力欄に打つスラッシュコマンド。実行する場所(チャンネル)が大事なものは明記。

## ① 各登壇が終わった瞬間 (登壇ごとに1回・どのチャンネルでもOK)

1人目が終わったら:

```
/lt_marker action:終了 number:1 label:山田さん「タイトル」
```

2人目が終わったら:

```
/lt_marker action:終了 number:2 label:佐藤さん「タイトル」
```

…以降、登壇者ごとに `number` を増やして同様に。

### 当日の登壇順 (コピペ用・終わった瞬間に打つ)

```
/lt_marker action:終了 number:1 label:せっきー
/lt_marker action:終了 number:2 label:友部さん
/lt_marker action:終了 number:3 label:リョータ
/lt_marker action:終了 number:4 label:石島さん
/lt_marker action:終了 number:5 label:みよっしー
/lt_marker action:終了 number:6 label:田島さん
```

※ 5人目は自分の登壇。降壇した直後に打つのを忘れない。

- `label` は登壇者名+タイトルなど自由記述(「いま終わった人」の情報)
- 画面には出ない(実行者にだけ確認が見える)。event-dbに仕切りが記録され、登壇者ごとに文字起こしを切り出せるようになる
- 余裕があれば登壇開始時に `action:開始` も打つとより正確(なくてもOK)

## ② LTセッション全体が終わった直後 (#lt-インサイト で実行)

```
/insight scope:LTセッション audience:参加者向け速報
```

- 生成に1〜2分。「今の盛り上がり」を共有してグループワークへの橋渡しに使う
- LTの文字起こし+lt-コメントを合体した内容でサマライズされる

## ③ 運営向け詳細がほしいとき (必ず #運営向け で実行)

```
/insight scope:LTセッション audience:運営向け詳細
```

- **実行チャンネル=event-db上の記録先**になるため、運営向けは `#運営向け` で打つのがリョータさんとの取り決め
- 急ぎでなければ撤収後でもOK
