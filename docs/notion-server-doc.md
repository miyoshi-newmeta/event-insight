## このサーバーの目的

単なる連絡用ではなく、**イベント中に生まれるデータ(登壇の発言・参加者のコメント・グループワークの会話とメモ)をリアルタイムに収集し、AIでサマライズして「参加者インサイト」としてその場で還元する**ための装置。収集したデータは (1) イベント当日の演出・議論の活性化、(2) 今後のイベント企画の改善、(3) 参加者のAI案件獲得・実務活用に役立つ知見の抽出、に使う。

## 裏側の仕組み (bot構成)

| bot | 役割 |
|---|---|
| APF (メインbot) | #lt-コメント と #メモ-グループ1〜6 の投稿を収集。コメントを会場スクリーンのオーバーレイに配信。スラッシュコマンド(/insight, /status)を提供 |
| APF2 | 🔊LT会場 に入り、登壇音声をリアルタイム文字起こし(Soniox STT + フィラー自動除去) → #lt-文字起こし に投稿 |
| APF3〜APF8 | 🔊グループ1〜6 にそれぞれ入り、グループ会話を文字起こし(チャンネルには流さずデータのみ保存) |

- 文字起こし・コメント・メモはすべて運営MacBook内に日付別JSONLで保存される
- 同じデータは外部イベントDB(VARET提供の event-db API / Cloudflare Workers + D1)にもリアルタイムでミラーされる(コメント・メモ・文字起こし → /api/comments、インサイト → /api/summaries)
- サマライズ/インサイト導出は DeepSeek v4 Pro (OpenRouter API) を使用
- bot・オーバーレイの実行環境は運営が当日会場に持ち込むMacBook Pro 1台

## 運営用コマンド (メインbotのスラッシュコマンド)

| コマンド | 説明 |
|---|---|
| `/insight scope:<全体/LT/グループN> audience:<参加者向け速報/運営向け詳細> minutes:<N>` | 収集データをAIがサマライズして投稿。参加者向けは400〜800字の速報、運営向けは網羅的レポート。minutes指定で「直近N分」に絞れる |
| `/status` | データ収集状況(件数)とスクリーン接続の確認 |

### インサイト投入の想定タイミング
1. **LT終了直後**: `/insight scope:LT` で速報 → グループワークへの橋渡し
2. **グループワーク中間(45分頃)**: `/insight minutes:45` → 他グループの議論を横共有して活性化
3. **クロージング**: `/insight scope:全体` で本日の総まとめを発表

## 参加者への案内ポイント (幹事が押さえておくこと)

- 参加者にお願いするのは2つだけ: **「LT中は #lt-コメント に気軽に書く」「グループワーク中は自分のグループのメモchに書く」**
- グループワークでは参加者各自が自グループのVCに参加する(スピーカー出力はオフにしてもらう)
- 発言・コメント・メモがAIで分析されてイベント中に還元されることは、ガイダンスで参加者に明示する(データの扱いの透明性)
- 参加者各自の端末でVCに参加してもらうため、事前のDiscord参加案内とガイダンスでのVC参加説明が重要

## 補足

- イベント後、`#インサイト` と `#資料共有` は参加者がいつでも見返せる「お土産」として残す
- 生データからの深掘り分析(企画振り返り・次回テーマ選定など)は運営側でイベント後に実施可能
