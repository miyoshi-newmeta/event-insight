# Discordの基礎知識 — 前提ゼロからわかる順番で

> 2026-10-07 のリハーサルで実際に説明した内容を、初めての人向けに並べ直したもの。

## 1. Discordってなに?

- もともとは**ゲーマーが一緒にゲームをしながら通話するためのアプリ**。今は**コミュニティ運営のプラットフォーム**として広く使われている。
- できることは**Slackとだいたい同じ**(チャンネルを分けて話す・カテゴリ分け・権限管理)。大きな違いは、**ボイスチャット(通話の部屋)が最初から組み込まれている**こと。Slackに「部屋に入って話す」機能はない。
- 名前の由来は "discord" = **「不和・調和の逆」**。ゲームコミュニティは人が増えると分裂しがちで、その分裂を解決するソリューションとして生まれた。

## 2. 「サーバー」= コミュニティの単位

- Discordでは、1つのコミュニティのことを**サーバー**と呼ぶ。
- 1人でいくつでも参加できるし、カジュアルにポンポン作れる(30個くらい入っている人もザラ)。
- 画面の**いちばん左の縦列**に、自分が参加しているサーバーのアイコンが並ぶ。

## 3. チャンネルは2種類ある — まずアイコンを見る

サーバーの中は**チャンネル**に分かれている。左側のチャンネル一覧で、頭のアイコンを見れば種類がわかる。

| アイコン | 種類 | なにをする場所? |
|---|---|---|
| **#** (シャープ) | **テキストチャンネル** | 文字のメッセージを書き込む(LINEやSlackと同じ) |
| **🔊** (スピーカーマーク) | **ボイスチャンネル** | 声で話す「部屋」。クリックで入退室する |

## 4. テキストチャンネル(#)の使い方

- チャンネルをクリックして開き、下の入力欄にメッセージを書いて送信するだけ。
- **通知がピコピコうるさいとき**: チャンネル名を**右クリック → 「チャンネルをミュート」**(通知オフ)。「ミュートを解除するまで」を選べばずっと静かになる。

## 5. ボイスチャンネル(🔊)の使い方 — 「部屋」のイメージ

- ボイスチャンネルは**部屋**みたいなもの。クリックすると入室、出ることもできる(出入り自由)。
- **同じ部屋にいる人どうしは、声が聞こえ合う**。自分が喋った声は、同じ部屋にいる全員(人もbotも)に届く。
- 初めて入るとき、ブラウザやアプリが**マイクの使用許可**を求めてくるので「許可」する。
- 入室すると**画面左下**に自分の操作ボタンが出る:
  - **マイクのアイコン** — 自分の声のオン/オフ(ミュート)
  - **ヘッドホンのアイコン**(マイクの右隣) — 相手の声・スピーカー出力のオン/オフ
- 自分が話すと**自分のアイコンが緑色に光る**。これがマイクが生きている証拠(=マイクテストはこれを確認する)。

## 6. このイベントでは、こう使う

ここまでが一般知識。ここからはAI Practice Forum特有の仕組み。

- **ボイスチャンネルにbot(APF2〜APF8)が入っている**。botは「同じ部屋の人」として声を聞き、**裏側で自動的に文字起こし**している(参加者には見えない。録音→文字起こしして裏で記録しているだけ)。
- 文字起こし・メモ・コメントなどのデータは、イベント情報をまとめるために**りょうた側で用意した記録用サーバー(Discordとは別物)にも送信**されている。
- **`#lt-コメント` に書いたコメントは、会場スクリーンにニコニコ動画風に流れる**。
- **`/insight` コマンド** — 集まったデータをAIがサマライズしてくれる:
  - 入力欄に `/insight` と打つと候補が出るので選ぶ
  - `scope`: 対象範囲(全体 / LTセッション / グループ全体 / グループ1〜6)
  - `audience`: **参加者向け速報**(短い・場が温まるトーン) / **運営向け詳細**(網羅的なレポート)の2モード
  - `minutes`: 直近何分ぶんを対象にするか(例: `10` なら10分さかのぼってサマライズ。省略すると今日全部)
  - 仕組み: 文字起こしデータに「あなたはイベントのインサイトアナリストです…」というプロンプトを合体させてAIに渡している。プロンプト次第で出力が変わる。
